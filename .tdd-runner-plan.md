## 4. Open Questions or Assumptions

1. **Preset Persistence:** This story stubs preset CRUD operations. Actual persistence is implemented in STORY-014, STORY-015, STORY-018. Preset dropdown will use mock/hardcoded data.

2. **Filter Field Set:** Initial implementation focuses on Owner, Date Range, and Stage fields as mentioned in touchpoints. Additional fields can be added following the same pattern.

3. **Widget Types:** Only graph widgets have explicit widget-local filter contracts today. The merge utility targets graph widgets specifically. Other widget types may need future extension.

4. **Permission Model:** "Can apply locally but cannot persist" logic will be stubbed in this story. Full permission enforcement comes in dependent stories.

5. **URL Encoding Format:** Will reuse existing `filter[field][op]=value` convention from View Bar implementation for consistency.
