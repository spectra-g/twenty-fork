## 6. Implementation Notes

**Pattern Parity:**
- Filter bar: Follow `ViewBar.tsx`, `ViewBarFilterDropdown.tsx`, `ViewBarDetails.tsx` patterns
- URL encoding: Follow `buildFilterQueryParams.ts`, `filterUrlQueryParamsSchema.ts` conventions
- Filter merging: Follow `shouldReplaceFilter.ts` same-field override precedent
- Hook patterns: Use `ObjectFilterDropdownComponentInstanceContext` for scoped state

**State Architecture:**
- Dashboard filter state lives in `useDashboardFilters` hook (per-dashboard instance)
- Widget filter state remains in `configuration.filter` on widget config
- Merge happens at query time in `useGraphWidgetQueryCommon.ts`
- URL hydration is one-time effect in `useApplyDashboardFiltersFromUrl`

**Edge Cases to Unit Test:**
- Empty dashboard filters (fallback to widget filters only)
- Same field in both dashboard and widget (dashboard wins)
- Clearing dashboard filter (reverts to widget filter)
- Malformed URL params (graceful skip)
- Multiple filter groups (AND semantics)
